Directions

Camera setup first, then how Jump Lab works on this phone.

Camera setup

  1. Side-on

    Sagittal view. The camera looks across the jump, not from the front.

  2. Tripod height

    About hip height, or level with the top of the box.

  3. Distance

    About 3–4 m away.

  4. Square to the plane

    Lens perpendicular to the plane of the jump.

  5. 1× lens

    No digital zoom.

  6. Full frame

    Whole body, the box, and the landing area stay in frame.

  7. Light

    Bright and even. Avoid shooting into a window.

  8. 240 fps

    iPhone slo-mo. The capture frame rate starts at 240.

How to use the app

  1. Jump Analysis

    Load a clip, mark step-off / touchdown / takeoff / landing, check the metric cards, save the jump. Today’s session shows means, baseline, flags, and raise-box.

  2. Optimal Box Height Analysis

    Stay on that screen. Add 3–5 box heights, upload one clip per height, check contact / jump height / RSI in each row (nudge marks if needed), then Submit test for the recommended working box. That run is the 4-week profile retest.

  3. Master log

    Every saved jump in one table. Export to Excel or CSV — the first columns match the Jump Test paste order in Byron’s workbook.

  4. Privacy

    Video stays on this phone. Only numbers are saved locally.
