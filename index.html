    Directions

    Camera setup first, then how Jump Lab works on this phone.

    Camera setup

    1. Side-on

      Sagittal view. The camera looks across the jump, not from the front.

    2. Tripod height

      About hip height, or level with the top of the box.

    3. Distance

      About 3–4 m away.

    4. Square to the plane

      Lens perpendicular to the plane of the jump.

    5. 1× lens

      No digital zoom.

    6. Full frame

      Drop/depth: whole body, the box, and the landing area stay in frame. One-step / penultimate: side-on, phone at hip height — keep the last two steps (penultimate + plant), takeoff, and landing fully in frame so plant and penultimate contact can be marked.

    7. Light

      Bright and even. Avoid shooting into a window.

    8. 240 fps

      iPhone slo-mo. The capture frame rate starts at 240.

    How to use the app

    1. Jump Analysis

      Load a clip, mark step-off / touchdown / takeoff / landing, check the metric cards, save the jump. Today’s session shows means, baseline, flags, and raise-box.

    2. Optimal Box Height Analysis

      Stay on that screen. Add 3–5 box heights, upload one clip per height, check contact / jump height / RSI in each row (nudge marks if needed), then Submit test for the recommended working box. That run is the 4-week profile retest.

    3. Master log

      Every saved jump in one table. Export to Excel or CSV — the first columns match the Jump Test paste order in Byron’s workbook. With a token, GitHub’s data branch is the jump log source of truth (bots read it too).

    4. GitHub sync token

      On GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate. Resource owner: your account. Repository access: only VerticalJumpAnalysis. Permissions: Contents → Read and write. Paste the token on Master log → GitHub sync. It is stored in this browser’s localStorage only — never committed or logged.

    5. Privacy

      Video stays on this device. Jump numbers save to your GitHub jump log (token in this browser only); this device keeps a cache if you are offline.

    Master log

    GitHub sync

    GitHub is the source of truth: the full log is written to data/jump-log.csv and data/jump-log.json on the data branch. This browser caches the log and queues offline edits.
